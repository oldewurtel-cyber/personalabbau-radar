Übersicht über öffentlich gemeldeten Stellenabbau, Insolvenzen, Schließungen/Verlagerungen und Kurzarbeit von Betrieben in der Region Hannover.

- Seite: https://oldewurtel-cyber.github.io/personalabbau-radar/
- Wird montags, mittwochs und freitags früh automatisch aktualisiert.
